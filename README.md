# HomeChat

**HomeChat** is a public and anonymous chat that simulates the rooms of a house. Each room represents a different part of the house where users can join, send messages, and interact in real-time without needing to identify themselves.

---

## Features

- Public and anonymous chat
- Rooms simulating different parts of a house
- Real-time messaging
- Responsive design (desktop and mobile)
- Modern interface built with React and Vite

---

## Technologies

- **Frontend:** React, Vite, Axios
- **Backend:** Supabase (realtime database)
- **Styling:** Pure CSS
- **State management:** useState, useEffect
